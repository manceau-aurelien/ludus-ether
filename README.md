# Ludus — L'École des Gardiens

Jeu de gladiateurs **incrémental** dans le navigateur : vous entraînez un champion qui combat seul, et vous dépensez l'expérience qu'il gagne dans ses arbres d'intelligence, de compétences, de statistiques et d'utilitaires. Coopération en ligne à deux, et le jeu de baston *Éclats d'Éther* en bonus.

**▶ Jouer : https://manceau-aurelien.github.io/ludus-ether/**

- Aucun téléchargement : le jeu tourne directement dans le navigateur (ordinateur recommandé, souris ou clavier).
- 5 écoles sauvegardées dans le navigateur, avec export / import de fichier.
- Coopération en ligne par code de salon (connexion internet requise).

Règles détaillées, commandes et coopération : voir [LISEZMOI.md](LISEZMOI.md).

Fait entièrement en JavaScript et Canvas, sans dépendance (hors PeerJS pour la coopération en ligne). Graphismes et sons générés par le code.
